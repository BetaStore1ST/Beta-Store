| الميزة | الوصف |
|--------|-------|

## 🎨 التصميم

- **خطوط:** Orbitron + Tajawal
- **ألوان:** نيون سماوي، بنفسجي، أخضر، وردي
- **تأثيرات:** Grid Background، Scanline، Neon Glow، Float Animation
- **تصميم:** RTL (عربي) بالكامل

## 📸 الصفحات

### 🏠 الرئيسية
- زر تسجيل الدخول بديسكورد
- زر لوحة التحكم  
- زر إضافة البوت للسيرفر

### 🔐 تسجيل الدخول
- ربط حساب ديسكورد
- عرض صورة الحساب مع علامة ✓ بالزاوية
- اسم المستخدم ورقمه

### ⚙️ لوحة التحكم
- **نظرة عامة** — إحصائيات وحالة البوت
- **إدارة التذاكر** — قفل/حذف/بحث
- **أنواع التذاكر** — تخصيص القائمة
- **رسالة الإيمبد** — تعديل + رفع صورة + معاينة
- **تخصيص الأزرار** — إضافة/تعديل/تلوين
- **رتب الإدارة** — Role IDs وصلاحيات
