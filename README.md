
# BetaStore Dashboard

## التشغيل

```bash
npm install
```

انسخ `.env.example` إلى `.env`

ثم ضع بيانات Discord Bot:

- CLIENT_ID
- CLIENT_SECRET

بعدها:

```bash
npm start
```

الموقع:
http://localhost:3000

## المميزات
- Discord OAuth Login
- Dashboard Neon Green
- Ticket Embed Builder
- Role ID Settings
- Discord User Avatar
- Add Bot Button
